# Graphite

MVP: создание/редактирование заметок, автосохранение Markdown, поиск.
В v0.1 не будет: синхронизации, сервера, mobile/web, плагинов, MinIO, авторизации.

Проект создан для обучения и открыт к вашим предложениям.
Он будет open source навсегда.

Одна из причин — мне надоели программы на Electron, которые потребляют 400 МБ–1 ГБ оперативной памяти на локальном компьютере.
Хочется написать приложение, которое по мере развития будет содержать немало функций, но при этом потреблять адекватные 100–200 МБ.

На данный момент приложение потребляет **61 МБ** оперативной памяти.

Проект делается вручную без ИИ. Напоминаю: в первую очередь он создан для изучения.
Но **в ваших pull requests может использоваться ИИ**.

Дизайн — второстепенная задача.
Главный упор — на оптимизацию.
